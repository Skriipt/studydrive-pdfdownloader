# Privacy Policy

StudyDrive PDF Downloader is a single-purpose browser extension for StudyDrive document pages.

## Data access

The extension runs only on URLs matching `https://www.studydrive.net/*/doc/*`.

It can inspect PDF data that the StudyDrive document preview has already loaded in the browser. This is used only to start a local browser download when the user clicks the `Download PDF` button.

## Data collection

The extension does not collect, sell, transmit or store personal data.

The extension does not send document data to external servers.

## Permissions

- `downloads`: required to save the captured PDF through the browser download API.
- `https://www.studydrive.net/*`: required so the extension can run on StudyDrive document pages.
